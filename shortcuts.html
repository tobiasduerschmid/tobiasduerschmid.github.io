Keyboard shortcuts

Most interactive widgets on this site can be operated entirely from the keyboard. This page lists every custom keyboard shortcut. Standard browser shortcuts (Tab to move focus, Enter to activate buttons and links, Space to toggle controls, etc.) are not repeated here.

On macOS, use Cmd wherever you see Ctrl, except for terminal shortcuts that explicitly require Control.

Music videos and narrations

These shortcuts work only while focus is inside a music player, including a player on the Video playlists page, or inside a narration player, where they act on the narration. Narration players are the narrated lessons (Node.js, React, Observer, State, Strategy, Model-View-Controller, UML class diagrams, UML sequence diagrams, UML state machine diagrams, UML component diagrams), the Scrum and Module Blood Groups video narrations, and the case studies (Therac-25, Cloudflare 2019, Hugging Face 2026). A case study without rendered speech has no narration clock, so only F and Esc apply there. Dropdowns and text fields keep their native keys. The position slider supports the seek shortcuts below and keeps its other native keys. Outside the player, these keys have their normal page behavior, except Escape also cancels an active playlist drag. In a knowledge check or a case-study decision, keys answer the question instead.

Step-through debugger

Available in tutorials that enable the Python, JavaScript, Prolog, or Haskell debugger. During a debug session, focus the debugger panel, its controls, or the code editor to use these shortcuts. Prolog steps follow resolution goals; Haskell steps follow demanded expressions. Their history controls inspect recorded events without repeating program effects.

Use Tab and Shift+Tab to reach debugger controls, and Enter or Space to activate buttons. In Breakpoints → Code Breakpoints, choose a file and line, then activate Add breakpoint. Use its Edit condition and Remove breakpoint buttons to manage it. Variable expanders, call-stack frames, and history entries are buttons. The history slider accepts arrow keys, Home, and End. Press Esc to leave the code editor and resume tab navigation.

Step controls in the inline debugger.
KeysAction
F5 Continue execution to the next breakpoint or until the program ends.
Shift+F5 Stop the debugger.
Alt+Shift+F5 Run backwards to the previous breakpoint.
F10 Step over the next line.
Shift+F10 Step backwards over the previous line.
Alt+Shift+F10 Step backwards out of the current function.
F11 Step into the next function call.
Shift+F11 Step out of the current function (or step backwards on return).
Enter Confirm a value entered in a watch or breakpoint input field.
Esc Cancel and close the active input field without saving.

Embedded tutorial terminal

In the Shell Scripting tutorial, focus the terminal and use Ctrl+C to request an interrupt. If a command such as cut is waiting for input and the interrupt does not work, use Ctrl+D on an empty input line to finish input; press Enter first if you have typed text. This does not stop an infinite loop. Both shortcuts use Control on macOS too.

The Python tutorials embed a small in-browser terminal under the editor for git, filesystem, and python commands. The terminal must be focused for these to take effect. macOS users can use Option wherever you see Alt. Ctrl+W and Ctrl+T are claimed by the browser on Linux and Windows (close tab / new tab) — use the Alt alternatives there.

Conflicts with browser and operating system shortcuts

The shortcuts above are scoped to specific widgets — they only fire while the widget is focused. None of them override browser-wide shortcuts (such as Ctrl+T for a new tab or Ctrl+W for closing a tab) or operating system shortcuts. The debugger keys (F5, F10, F11) shadow the browser’s reload and devtools shortcuts; this only happens during a debug session while focus is in the debugger or its code editor. Move focus outside them to use the browser’s default behaviour. On a focused diagram item of the UML editors, Shift+F10 and the Menu key open the item's own menu in place of the browser's context menu, as a right-click there does. In the C4 editor, Ctrl+=, Ctrl+−, and Ctrl+0 magnify the drawing instead of the page, and Ctrl+Z and Ctrl+Y undo and redo the model; the magnification keys only work while focus is in the editor’s drawing, so the browser’s page zoom works everywhere else, and the undo keys work in the drawing and in the YAML tab, where they replace the text field’s own undo.

Reporting accessibility issues

If a shortcut on this page does not work, or if you encounter an interactive widget that cannot be operated by keyboard, please open an issue on GitHub.
