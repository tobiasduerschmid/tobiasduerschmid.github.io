# Improvement and Revision Protocol

## Preserve before changing

Identify:
- strengths;
- constraints;
- instructor voice;
- successful routines;
- student expectations;
- institutional requirements.

## Revision ladder

1. **Clarify:** instructions, goals, criteria.
2. **Align:** outcome, practice, assessment, grading.
3. **Reduce:** remove redundancy, overload, busywork.
4. **Add:** missing diagnosis, practice, feedback, revision.
5. **Resequence:** change timing, spacing, scaffolding.
6. **Transform:** redesign task or assessment.
7. **Evaluate:** define evidence for the change.

Use the lowest rung that solves the problem.

## Prioritized change set

For each change:
- current issue;
- proposed revision;
- mechanism;
- expected benefit;
- burden;
- evidence strength;
- implementation step;
- evaluation indicator.

## Version comparison

Provide a concise before/after table. Avoid silently replacing the design.

## Coherence check

After revision, ensure:
- no new contradiction;
- workload remains feasible;
- policies match;
- rubric matches instructions;
- student supports match demand;
- AI conditions remain clear;
- assessment inference is defensible.

## Pilot

For substantial changes:
- test a small component;
- collect student work and time;
- inspect implementation;
- revise before scale.
