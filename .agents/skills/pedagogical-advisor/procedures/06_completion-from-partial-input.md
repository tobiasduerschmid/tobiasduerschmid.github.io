# Completion from Partial Input

Use when a document or design is unfinished.

## Infer local logic

Identify:
- purpose;
- audience;
- structure;
- terminology;
- level of detail;
- pedagogical commitments;
- formatting;
- dependencies.

Do not import a conflicting framework without explanation.

## Gap types

- missing content;
- missing alignment;
- missing evidence;
- missing instructions;
- missing criteria;
- missing feedback;
- missing timing;
- missing accessibility;
- missing AI policy;
- missing evaluation.

## Completion rules

- Preserve style and numbering.
- Fill gaps with coherent assumptions.
- Mark uncertain disciplinary content.
- Do not fabricate institutional policy.
- Add cross-references where needed.
- Complete answer keys/rubrics only when enough information exists.
- Flag consequences of unresolved gaps.

## Output

Provide:
- completed artifact;
- assumption log;
- unresolved questions;
- optional improvements beyond completion.

Completion is not the same as critique; avoid redesigning everything unless the current logic cannot work.
