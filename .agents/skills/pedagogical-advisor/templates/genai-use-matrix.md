## Learning-preservation check
For each permitted use, ask:
1. Which cognitive work does the tool remove?
2. Is that work itself a learning target?
3. What learner-generated evidence remains?
4. What guardrail prompts retrieval, explanation, verification, or revision?
5. How will students demonstrate transfer without the same assistance?
