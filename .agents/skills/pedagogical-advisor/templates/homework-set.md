## Design checks
- [ ] Every problem has a distinct learning function.
- [ ] Volume is not being used as a substitute for deliberate practice.
- [ ] Students receive corrective information before errors become habits.
- [ ] Challenge rises through fading rather than hidden assumptions.
- [ ] Related problem types are mixed when method selection matters.
- [ ] Core learning returns after a delay.
- [ ] Completion time was piloted or estimated for different preparation levels.
- [ ] Required tools and data are accessible.
- [ ] AI rules preserve the intended cognitive work.

## Instructor key
For each problem, record:
- target knowledge/strategy;
- full solution/reasoning;
- common error and cause;
- partial-credit or feedback rule;
- decision about reteaching or next practice.
