## Suggested 45-minute session

These timings are a starting budget, not an evidence-based optimum.

| Minutes | Action | Product |
|---|---|---|
| 0–5 | Revisit target capabilities, instructions, and criteria | Shared interpretation of the task |
| 5–15 | Independently mark three short samples | Criterion scores, exact evidence, one useful next-step comment |
| 15–30 | Compare disagreements and inspect the work | Clarified descriptors and accepted alternatives |
| 30–40 | Mark a fresh short sample independently | Check whether the clarification resolves the issue |
| 40–45 | Agree on monitoring and unresolved cases | Decision log and sampling plan |

Adjust the session and sample length to the complexity of the work; long projects need a larger budget or selected excerpts.

## Decision log

| Question or disagreement | Decision and reasoning | Example | Affected submissions / criteria | Who follows through |
|---|---|---|---|---|
| | | | | |

Resolve explicitly:

- Whether one underlying error has been penalized more than once;
- When a later step earns credit despite an earlier error;
- How alternative correct methods satisfy the same criterion;
- What missing evidence means, without guessing intent or misconduct;
- Which communication features are relevant to the learning target;
- When a score requires a second review.

## Comment bank with adaptation

| Misconception or issue | Located evidence to insert | Comment stem | Student's next opportunity to act |
|---|---|---|---|
| Unsupported assertion | | “Your claim at [location] needs [specific evidence]. On the next attempt, [action].” | |
| Correct result, fragile reasoning | | “The result is correct. Explain [decision] so the reasoning also works when [variation].” | |
| Effective strategy | | “Your [specific move] makes [criterion] visible; retain it when you revise [other issue].” | |

Adapt every comment to the actual work. A comment bank reduces repetition; it does not replace reading or judgment.
