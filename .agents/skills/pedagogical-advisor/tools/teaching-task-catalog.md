# Teaching task catalog

Choose a task family, then deliver the smallest complete output. This catalog extends the original course, lecture, assessment, and homework routes. Templates are starting structures, not mandatory blank forms.

| User request | Deliverable that resolves it | Route |
|---|---|---|
| Build a course | Outcomes, progression, practice/assessment map, workload and evaluation | `procedures/07_course-design-workflow.md` |
| Trim an overloaded syllabus | Prioritized cut/keep/merge decisions with consequences | `tools/teaching-decision-cards.md` |
| Align a degree/module sequence | Capability-by-course progression and gaps | `procedures/19_ai-era-curriculum-and-coaching.md` |
| Design one class | Timed instructor/student moves, prompts, expected responses, fallback | `procedures/08_lecture-design-workflow.md` |
| Repair a lecture deck | Locator-specific repairs, preserved design constraints, checked artifact | `procedures/16_material-review-and-repair.md` |
| Explain a difficult concept | Prerequisite bridge, example/nonexample, misconception probe | `knowledge/08_cognitive-load-and-multimedia.md` |
| Improve a demonstration | Prediction, controlled comparison, trace, debrief, independent check | `tools/teaching-decision-cards.md` |
| Write instructor notes | Explanations, transitions, likely questions, facilitation responses | `procedures/08_lecture-design-workflow.md` |
| Adapt a reading | Purpose, reading questions, vocabulary support, application | `procedures/16_material-review-and-repair.md` |
| Create a study guide | Prioritized capabilities and retrieval/application prompts with feedback | `procedures/11_homework-design-workflow.md` |

Ordinary factual edits need no full course redesign. A requested artifact needs actual usable content, not a catalog of possibilities. Apply a file-format skill only when that deliverable benefits from it and the capability is available.
