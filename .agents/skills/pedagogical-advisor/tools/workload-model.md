# Workload and Feasibility Model

Good designs fail when time is fictional. Estimate burden before committing to a pedagogical method.

## Student workload model

Estimate **engaged time**, not page counts alone.

| Activity | Base estimate | Adjustment questions |
|---|---:|---|
| Accessible reading | 15–30 pages/hour | Density, prior knowledge, note taking, language |
| Technical reading | 5–15 pages/hour | Equations, diagrams, unfamiliar vocabulary |
| Video/lecture viewing | 1.2–1.8 × runtime | Pausing, retrieval prompts, note making |
| Routine problem | observed pilot median | Novice vs competent time; debugging |
| Complex problem/case | pilot or expert time × 2–4 | Research, false starts, collaboration |
| Drafted writing | 250–500 polished words/hour | Source use, revision, discipline conventions |
| Research/source evaluation | 2–6 credible sources/hour | Database access and source difficulty |
| Group coordination | add 15–30% | Scheduling, role clarity, tool friction |
| Revision | 25–60% of initial production time | Feedback scope and depth |
| Retrieval practice | 5–20 minutes/session | Frequency and feedback |

These are planning ranges, not universal facts. Pilot with representative students and ask for time-on-task data.

### Weekly student workload calculation

For each week:

`total = contact + preparation + practice + production + collaboration + revision + assessment preparation`

Report:
- median expected time;
- likely range for less-prepared and highly prepared learners;
- peak week;
- simultaneous deadlines across courses when known;
- which task can be reduced if actual time exceeds the budget.

## Instructor and TA workload model

### Preparation

| Design | Typical first-run burden | Reuse potential |
|---|---|---|
| New lecture with examples | moderate–high | high if revised from evidence |
| Active-learning questions | high cognitive design, low delivery | high |
| Case/PBL unit | high | high with facilitator notes |
| Auto-graded retrieval | high setup | very high |
| Authentic project | high setup and coordination | medium–high |
| AI-integrated task | high initial testing and policy work | uncertain due tool change |

### Marking estimate

`marking hours = enrolment × minutes per submission ÷ 60 × number of submissions`

Add:
- 10–20% for administration and exceptions;
- calibration/moderation time for multiple markers;
- feedback-revision cycles;
- academic-integrity follow-up;
- accessibility and alternative-format work.

### Feedback budget strategies

Use the least expensive method that still creates usable information:
- whole-class feedback on common patterns;
- sampled comments plus rubric dimensions;
- automated feedback for low-level correctness;
- peer/self-assessment after training;
- audio/video feedback only when it saves time and remains accessible;
- staged checkpoints to prevent expensive late failures;
- comment banks customized to the work;
- office-hour or studio feedback for complex decisions;
- selective feedback: one global and two local priorities.

Do not increase feedback volume unless students will use it.

## Feasibility scorecard

Rate each 0–3.

| Dimension | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Student time | unknown/impossible | likely overload | plausible with risk | piloted/credible |
| Marking | impossible | depends on unpaid excess | manageable with redesign | sustainable |
| Facilitation | no staffing plan | fragile | adequate | calibrated and robust |
| Technology | inaccessible/unreliable | major dependency | supported | supported with fallback |
| Room/schedule | incompatible | substantial workaround | workable | well matched |
| Accessibility | reactive only | known barriers | planned options | tested and integrated |
| Policy/AI | contradictory | ambiguous | mostly explicit | coherent and teachable |
| Reusability | one-off | low | moderate | high |

A score below 2 on any mission-critical dimension requires revision or a contingency.

## Substitution rule

Every added requirement must answer:

> What lower-value activity, content, or grading practice does this replace?

“Add” without “remove, simplify, automate, sample, or combine” is not a sustainable course-design strategy.
