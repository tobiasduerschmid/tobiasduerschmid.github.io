# Homework and Assignment Design Rubric

Score 0–3.

| Dimension | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Learning function | Compliance/busywork | Generic practice | Each section has a purpose | Sequence deliberately supports retrieval, mastery, discrimination, and transfer |
| Alignment | Unrelated to outcomes/assessment | Content overlap only | Demand aligned | Homework prepares and provides evidence for later capability |
| Prerequisites/guidance | Hidden assumptions | Help only after failure | Models/hints available | Worked examples, completion, hints, and fading match expertise |
| Practice quality | Massed repetition | Large volume | Sufficient varied practice | Spaced, cumulative, interleaved where method selection matters |
| Feedback | No/late feedback | answers only | timely corrective feedback | required correction/retry and instructor response to patterns |
| Difficulty | Arbitrary surprise | mostly routine or uniformly hard | purposeful progression | desirable difficulty with clear support and challenge route |
| Workload | unbounded/unknown | likely excessive | estimated | piloted range, time guidance, and low-value items removed |
| Access/equity | requires unequal resources/time | generic flexibility | accessible tools/options | cost, language, technology, collaboration, and caregiving constraints designed for |
| Collaboration | rules absent | permitted but vague | clear boundaries | collaboration supports explanation while retaining individual accountability |
| GenAI | ambiguous or outsourcing invited | blanket ban | task-specific rule | phases preserve cognitive work, require verification/disclosure, and include independent evidence |
| Connection | collected and forgotten | graded only | discussed or used later | homework evidence shapes teaching and returns through cumulative use |

Low homework completion can be a design signal—value, time, feedback, access, or difficulty—not only a character judgment.
