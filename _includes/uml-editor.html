{% comment %} Reusable ArchUML editor include. LIMITATION: Only ONE instance per page is supported. The editor binds to fixed DOM IDs (uml-pg-type, uml-pg-input, uml-pg-output, …); a second include on the same page would silently rebind the second init() to the first include's DOM. If you need two editors on one page, this include needs to be parameterized with an instance suffix first. Supported options: - types: comma-separated diagram type ids - default_type, default_layout - start: "example" or "empty" - persistence: "true" or "false" for localStorage-backed drafts and pane sizes - storage_key: optional scope string. When set, autosave keys become "uml-pg-autosave--" instead of "uml-pg-autosave-". Use this on pages (like tutorials) that should not share drafts with the global UML playground. - default_editor_size, default_props_size: optional pane widths in px - reset_label, reset_title - hide_archuml: "true" or "false" to hide the source pane and Copy ArchUML - hide_syntax_help: "true" or "false" to hide the link to the ArchUML syntax reference - export_types: optional comma-separated types to download together instead of the active diagram; Quick tips
  • Add Click a palette tool, then click the canvas — or drag the tool onto it.

Diagram preview

Preview updates as you edit ArchUML. In visual edit mode, Tab reaches diagram items; Enter selects an item; arrow keys nudge selected elements; Delete removes selected items. Shift+F10 or the Menu key opens a focused item's menu, which offers Move… and, for a line, its bends; while a move runs, arrow keys move it, Enter places it, and Escape cancels.
