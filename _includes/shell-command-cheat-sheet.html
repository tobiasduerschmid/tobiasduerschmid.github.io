Shell command cheat sheet

A quick reference for common Unix shell commands, including tools beyond these exercises. This browser lab runs a subset of them; interactive terminal programs, remote access, native builds, archives, and operating-system job control need a regular terminal. Options can differ between systems.

Navigate and manage files

  • pwd — print the current directory's path.
  • ls — list directory contents; -a includes hidden names, and -l shows details.
  • cd DIR — change directory; cd .. moves to the parent, and cd goes home.
  • mkdir DIR — create a directory; -p also creates missing parents.
  • touch FILE — update timestamps, creating an empty file if it is missing.
  • cp SOURCE DEST — copy files; -R also copies directories and their contents.
  • mv SOURCE DEST — move or rename files and directories.
  • rm FILE — remove a file; -r removes directories and their contents.
  • rmdir DIR — remove an empty directory.
  • ln -s TARGET LINK — create a symbolic link to a target path.
  • find DIR -name 'PATTERN' — search a directory tree for matching names; quote the pattern so the shell does not expand it first.
  • file FILE — identify a file's likely type from its contents.
  • du -h DIR — show disk space used by a directory and its contents in readable units.
  • df -h — show used and available space on filesystems.

Read and search text

  • cat FILE... — print files in order; with no file, copy standard input to standard output.
  • less FILE — browse a file interactively, one screen at a time.
  • head -n N FILE — print the first N lines.
  • tail -n N FILE — print the last N lines; -f follows newly appended data.
  • grep 'PATTERN' FILE — print lines matching a regular expression; -E enables extended syntax, -i ignores case, and -v selects nonmatching lines.
  • grep -F 'TEXT' FILE — match literal text instead of interpreting regular-expression symbols.
  • wc FILE — count lines, words, and bytes; -l counts only lines, and -m counts characters.

Transform and compare text

  • cut -f LIST FILE — extract numbered fields, separated by tabs by default; -d CHAR sets another delimiter.
  • sed 's/OLD/NEW/' FILE — replace the first match of a regular expression on each line; a trailing g replaces every match.
  • awk 'PATTERN { ACTION }' FILE — select records and process fields; $1 is the first field, and $0 is the whole record.
  • tr SET1 SET2 — replace characters from standard input; -d SET deletes characters.
  • sort FILE — order lines lexically using the current locale; -n compares numerically, and -r reverses the order.
  • uniq FILE — collapse adjacent repeated lines; -c prefixes each group with its count.
  • paste FILE1 FILE2 — combine corresponding lines into tab-separated columns.
  • diff FILE1 FILE2 — show line-by-line differences; -u includes surrounding context.
  • comm FILE1 FILE2 — compare two sorted files, separating lines unique to each file from lines they share.
  • xargs COMMAND — turn standard input into arguments for a command; use -0 with null-separated input for filenames containing spaces.

Shell settings, permissions, and help

  • echo TEXT — print arguments followed by a newline.
  • printf FORMAT ARG... — print formatted text; include \n when you want a newline.
  • man COMMAND — read a command's manual; this lab provides short references for cut, sed, grep, and awk.
  • help COMMAND — read Bash's help for a built-in command.
  • type COMMAND — show whether a name resolves to an alias, function, built-in, or executable.
  • which COMMAND — locate an executable on the command search path.
  • chmod MODE FILE — change access permissions; chmod u+x FILE adds execute permission for the owner.
  • chown OWNER FILE — change a file's owner, subject to system permissions.
  • export NAME=value — set a variable and make it available to child processes.
  • env — list environment variables, or run a command with a modified environment.
  • source FILE — execute a script in the current shell; . FILE is another spelling.
  • read NAME — read a line from standard input into a shell variable.
  • history — list commands remembered by an interactive shell.
  • whoami — print the current effective user's name.
  • date — display the current date and time.
  • clear — clear the terminal display.

Processes and jobs

  • ps — show a snapshot of selected running processes.
  • top — monitor processes and resource use interactively.
  • kill PID — send a signal to a process, normally requesting termination.
  • jobs — list jobs managed by the current shell.
  • fg / bg — resume a shell job in the foreground or background.
  • sleep N — pause for N seconds.
  • time COMMAND — report how long a command takes.

Remote access, archives, and development

  • ssh USER@HOST — open a secure remote shell or run a remote command.
  • scp SOURCE DEST — copy files between local and remote machines over a secure connection.
  • curl URL — transfer data from a URL, normally printing the response body; -o FILE saves it.
  • wget URL — download a resource to a file.
  • tar — create or extract archives; -cf creates an archive file, and -xf extracts one.
  • gzip FILE / gunzip FILE.gz — compress or decompress a file, replacing the input by default.
  • zip / unzip — create or extract ZIP archives.
  • make TARGET — build a target using the rules and dependencies in a makefile.
  • gcc / g++ — compile C or C++ source code.
  • git — track versions and collaborate on source code; git status summarizes working-tree changes.
  • nano FILE / vim FILE — edit a file in a terminal text editor.

Pipes and redirection (shell syntax)

  • A | B — send command A's standard output to command B's standard input.
  • COMMAND > FILE — write standard output to a file, creating or overwriting it.
  • COMMAND >> FILE — append standard output to a file.
  • COMMAND < FILE — read standard input from a file.
  • COMMAND 2> FILE — write standard error to a file.
  • COMMAND > FILE 2>&1 — send both standard output and standard error to the file; redirections are processed left to right.
  • A && B — run B only if A succeeds; A || B runs B only if A fails.
  • A ; B — run A, then B regardless of A's exit status.
  • COMMAND & — start a command in the background.
