{%- comment -%} Print always uses the light palette, regardless of the saved site theme. head.html includes this for the shared layouts. Add it to the of every other page that can carry the `dark-mode` class (pop-outs, narration readers). While print mode is active the controller sets `print-light-mode`, keeps `dark-mode` off, and restores both once printing ends, so the reader's saved preference and cookie stay unchanged. It is safe on a document that is print-light by design: that document keeps the class it started with. {%- endcomment -%}
