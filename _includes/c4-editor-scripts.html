The editor files and their order come from js/ArchUML/c4/manifest.json (`editor`, via _data/archuml_c4_manifest.json), as c4-scripts.html takes the core and renderer lists from it. The diagram editor's core group (js/ArchUML/diagram-editor/, with its stylesheet) comes first, deferred like the editor scripts, so the editor finds it when it edits a UML-notation view (code, deployment, dynamic, interfaces).
